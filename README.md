# Low Profile

Small privacy tools for everyday sharing. Everything runs in the browser: no uploads, no accounts, no tracking.

| Tool | What it does |
|---|---|
| [Scrub](scrub/) | Shows the GPS location, device and date hidden in photos, and saves clean copies with that data removed |
| [Redact](redact/) | Masks emails, phone numbers, IBANs (checksum-validated), card numbers (Luhn-validated), IP addresses and custom words in any text |
| [Wi-Fi Card](wifi-card/) | Generates a printable Wi-Fi QR card locally; the password is never stored |

Each tool is one HTML file with no build step. Wi-Fi Card uses the MIT-licensed [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator) library from cdnjs.
